## About me

I'm a full-stack engineer who cares about clean, maintainable software design. Since 2022 I've worked at **Electronic Arts**, building features end to end, from UI/UX to backend services, CI/CD and cloud infrastructure, and I've contributed to the release of EA's latest games.

I hold an **M.S. in Intelligent Systems and Artificial Vision** (magna cum laude, thesis grade 10.00), so I also enjoy working where software meets machine learning. Lately that means building AI agents with Claude and the **Model Context Protocol**.

- 🎮 **Now:** Full-Stack Software Engineer at Electronic Arts (C#, .NET, TypeScript, React, Go, Kubernetes)
- 🌱 **Learning:** Claude, MCP servers and clients, and agentic workflows
- 💬 **Ask me about:** .NET and Go backends, React/Next.js frontends, MongoDB aggregation pipelines, computer vision
